# PicoBalloon-2026
The working name of this radiosonde is PicoFalcon.

This repository contains HW design with custom antenna modelling and FW for MCU.

It is based on the popular 8-bit MCU ATmega328p. The reason of choosing this MCU was simple. It was available in my household supplies.

The air-gound communication is based on LoRaWAN. It is done by radio module RFM95 which supports LoRa CSS (Chirp Spread Spectrum) modulation.
